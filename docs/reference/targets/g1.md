# G1 and SONIC

Send retargeted G1 motion to GR00T Whole-Body Control through a SONIC ZMQ publisher. The deployment stack executes the policy in MuJoCo or on a real G1.

## Prepare the deployment stack

Install and configure GR00T-WholeBodyControl on the deployment machine. For the bundled simulation launcher, place the checkout at:

```text
thirdparty/GR00T-WholeBodyControl/
```

The launcher expects its `.venv_sim` environment and `gear_sonic_deploy/deploy.sh` to be ready, and requires `tmux`. Robot descriptions and collision assets come from RoboKit.

## Start a recorded stream

From the RetargetingKit checkout:

```shell
uv run --extra vis scripts/teleop/humanoid.py bvh_g1_sonic_viser
```

This publishes a sample BVH clip on port `5556` and opens Viser. `_viser` adds a viewer while keeping the SONIC stream active. For a viewer without a publisher, use the first example in [humanoid teleoperation](../../guide/humanoid_retargeting.md).

In a second terminal, launch simulation:

```shell
bash scripts/tools/launch_sonic_sim.sh
```

In the deployment pane, press `]`, then `Enter`, to start the policy. The script creates a `sonic_sim` tmux session and replaces an existing session with that name.

## Connect a real G1

After validating the retargeted motion and preparing the robot deployment stack, run this from its `gear_sonic_deploy` directory on the robot:

```shell
bash deploy.sh real --input-type zmq \
    --zmq-host <WORKSTATION_IP> --zmq-port 5556 --zmq-topic pose
```

This selects real robot deployment. Use the deployment controls and physical emergency stop described by your G1 setup. The workstation must run a SONIC preset and be reachable on port `5556`.

## What the stream contains

`SonicTarget` receives a `BasePoseQPosCommand`, estimates and smooths joint velocities, and converts 29 joint positions and velocities from G1 URDF order to SONIC order. It sends the root quaternion and joint data on topic `pose`; root translation is omitted.

The default publisher binds `tcp://*:5556`. Live Axis Studio, PICO, and dual Inspire hand workflows are covered in [humanoid teleoperation](../../guide/humanoid_retargeting.md).
