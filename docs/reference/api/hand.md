# Hand retargeter API

Hand retargeters consume a canonical `HandFrame` and return joint positions in the target URDF's order. Choose [optimization](../../guide/hand_retargeting.md) for per-frame solving or a [neural model](../../guide/neural_hand_retargeting.md) for a trained mapping.
